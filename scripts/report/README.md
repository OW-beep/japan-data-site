# 自治体調査レポート生成

全国自治体データランキングの有料レポート(PDF)を、サイトの公開データ
(data/*.json)から自動生成するスクリプト一式。

## セットアップ

```bash
cd japan-data-site-main
python3 -m venv .venv-report
.venv-report/bin/pip install reportlab matplotlib
```

日本語フォントは fonts/ の IPAexゴシック(IPAフォントライセンス v1.0)を
同梱して使う。チャート側(matplotlib)はシステムの Noto Sans CJK を使う。

## 生成

```bash
# 自治体コード(5桁)を指定。泊村=01403、夕張市=01209
.venv-report/bin/python scripts/report/build_pdf.py 01403
# → public/reports/<slug>.pdf(サンプル2件は従来のファイル名に合わせている)
```

- `generate_report.py`:データ読み込み・指標計算・複合スコア
  (lib/compositeScores.ts の定義に準拠。母集団の定義はレポート付録に明記)
- `charts.py`:将来推計グラフ、財政指標バー、レーダーチャート、
  産業構成、パーセンタイル帯
- `build_pdf.py`:PDFの組み立て(全17ページ構成)
- `assets/`:表紙用の実写真(Wikimedia Commons、CCライセンス)とクレジット情報

## レポート構成(17ページ)

1. 表紙(実写真+4つの複合スコアと評価)
2. 本レポートの使い方(キーファクト+目的別・読むべき章)
3. エグゼクティブサマリー(強み・注視点・構造的リスク+全国ポジション)
4. 基本プロフィール(主要指標×全国順位×全国平均)
5. 人口動態と将来推計(自然/社会動態、社人研推計2050年まで)
6. 財政健全度(5指標の3者比較、レーダー、財政規模)
7. 産業・雇用・所得(産業構成、失業率、課税所得、法人登記動向)
8. 医療・福祉・子育て・生活基盤(複合スコアと施設指標)
9. 住宅・地価・ふるさと納税
10. 類似自治体ベンチマーク(人口規模が近い10団体との比較)
11. 多角分析①(財政力×人口動態、高齢化×医療の散布図と類型化=3次分析)
12. 多角分析②(2050年シナリオ試算、従属人口指数、転換点=4次分析)
13. ビジネス判断のための指標(域内所得総額、労働力の将来、予算規模)
14. 考察(財政の持続可能性、人口構造の転換、産業構造、広域連携)
15. 診断と展望(ルールベース自動診断)
16. 付録(指標の定義・算出方法・出典・写真クレジット・免責)
